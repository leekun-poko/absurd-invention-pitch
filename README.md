A one-sentence pitch for an absurd invention: the LockWitness, a $39 doorknob that photographs your hand locking the door and posts you the dated picture, so you can stop turning the car around to check a door you definitely locked. Running the program writes the pitch to entry.txt in the output directory.

## Run it

```sh
python3 main.py
```
